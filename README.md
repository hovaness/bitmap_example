# Delphi Taxi Backend Service

Современное бэкенд-приложение на языке Delphi (совместимо с Delphi 10 / Delphi 13 Florence), демонстрирующее применение разделения ответственности (Separation of Concerns) и Enterprise-паттернов в экосистеме Object Pascal.

Проект разработан в рамках демонстрации навыков быстрой адаптации и перехода с платформы .NET (C#) на стек Delphi + PostgreSQL.

## 🏗 Архитектура проекта

Приложение спроектировано по классической слоистой архитектуре (Layered Architecture) без визуального зацепления (UI-agnostic):

*   **Domain Model (`uOrderModel.pas`)** — Чистые сущности бизнес-домена. Поля инкапсулированы через строго типизированные свойства (`property`) с разграничением прав доступа.
*   **Data Access / Repository (`uOrderRepository.pas`)** — Изолированный слой работы с СУБД **PostgreSQL** на базе компонентов **FireDAC**. Логика выборки построена на оптимизированных сырых SQL-запросах с использованием обобщенных табличных выражений (**CTE WITH**). Реализованы механизмы логического резервного копирования (`pg_dump`).
*   **Application Service (`uTaxiService.pas`)** — Слой бизнес-логики. Отвечает за оркестрацию данных, расчеты финансовых показателей (выручка, KPI), отказоустойчивую обработку исключений (`try..except`) с кастомным логированием.
*   **Reporting Component** — Модуль интеграции с генератором отчетов **FastReport 5.x**. Передача данных из доменного слоя в отчет реализована динамически через `TfrxUserDataSet` и анонимные методы (лямбды) без использования визуального связывания на формах.

## ⚡ Ключевые паттерны и подходы

*   **Детерминированное управление памятью:** Полный контроль жизненного цикла объектов. Безопасное освобождение ресурсов в куче с помощью конструкций `try..finally` и вызовов метода `.Free`, исключающих появление утечек памяти (Memory Leaks) и зависших указателей.
*   **Современный синтаксис Object Pascal:** Активное применение параметризованных коллекций (`System.Generics.Collections.TObjectList<T>`) с флагом владения объектами (`Owned = True`), строго типизированных итераторов `for-in` и анонимных процедур.
*   **Процессная интеграция:** Структура именования коммитов и декомпозиция кода подготовлены для бесшовной интеграции с баг-трекером **Redmine** (автоматическое закрытие тикетов через смарт-коммиты).

## 🛠 Стек технологий
*   Delphi 10 / Delphi 13 Florence (Win32 target)
*   FireDAC Data Access Framework
*   PostgreSQL 15+ (PL/pgSQL, CTE WITH)
*   FastReport 5.x Backend Engine
